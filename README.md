# Associação Comunitária Esperança

## MVP para gestão comunitária

Sistema web desenvolvido para apoiar a gestão de participantes, atividades, inscrições, controle de vagas e registro de presença da Associação Comunitária Esperança.

## Funcionalidades

- Cadastro e consulta de participantes
- Cadastro e consulta de atividades
- Controle de inscrições
- Controle de vagas
- Registro de presença
- Organização das informações em um único sistema

## Tecnologias

- Python 3.12
- Django 5.x
- SQLite para desenvolvimento inicial
- HTML e Django Templates

## Estrutura

O projeto utiliza uma arquitetura organizada por aplicações Django, separando os módulos de participantes, atividades, inscrições e presenças.

## Objetivo

O MVP busca reduzir a dependência de registros manuais e facilitar o controle das informações utilizadas nas atividades da associação.
